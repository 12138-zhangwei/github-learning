# GitHub Learning

A small, honest record of my journey learning programming and GitHub.

## Goals

- Learn the basic Git workflow: clone, branch, commit, pull, and push
- Practice programming fundamentals with small exercises
- Write clear README files and learning notes
- Build projects that are simple, complete, and reproducible

## Run the example

Python 3 is required.

```bash
python src/hello.py
```
