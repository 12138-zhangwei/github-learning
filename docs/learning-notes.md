# Learning Notes

## Git essentials

| Command | Purpose |
| --- | --- |
| `git status` | Check changed and staged files |
| `git add <file>` | Stage a file for the next commit |
| `git commit -m "message"` | Save a meaningful checkpoint |
| `git pull` | Get remote changes |
| `git push` | Send local commits to GitHub |
| `git switch -c <branch>` | Create and enter a new branch |

## A useful daily workflow

1. Pull the latest changes.
2. Create a branch for one small task.
3. Make and test the change.
4. Review `git diff`.
5. Commit with a clear message.
6. Push the branch and open a pull request.
